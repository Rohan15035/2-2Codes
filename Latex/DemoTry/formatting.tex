\section{Text Formatting Reference}

\subsection{Emphasis Commands}

This sentence contains \textbf{bold text}, \textit{italic text},
\emph{emphasized text}, and \underline{underlined text}.

Here is \textbf{\textit{bold and italic combined}}, and here is
\emph{emphasis containing \textbf{bold} inside it}.

\subsection{Font Size Scale}

Below is every standard size declaration, smallest to largest,
applied to the same sample phrase so you can compare them directly.

{\tiny This is tiny text.}\\
{\scriptsize This is scriptsize text.}\\
{\footnotesize This is footnotesize text.}\\
{\small This is small text.}\\
{\normalsize This is normalsize text.}\\
{\large This is large text.}\\
{\Large This is Large text.}\\
{\LARGE This is LARGE text.}\\
{\huge This is huge text.}\\
{\Huge This is Huge text.}

\subsection{Sizes Inline, As Used in a Sentence}

Font sizes can also vary such as {\Large Large text}, {\small small
text}, and {\huge huge text}, all sitting inside one sentence the
way a real paragraph would use them.

\subsection{Combined in a Single Paragraph}

This article highlighted the importance of \textbf{structured
writing} using \LaTeX{}. The use of \textit{formatted text},
mathematical expressions, tables, and figures improves both
\underline{readability} and presentation quality, especially when
\emph{emphasis} is used to draw attention to a key term.
